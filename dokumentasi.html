01

Pendahuluan

Dokumentasi ini merinci proses teknis dan metodologi dari proyek "Akuisisi Data dan Pemetaan Dusun Tegalsari" — sebuah implementasi Praktik Kerja Lapangan 2 (SVIG223439) yang mengintegrasikan data spasial ke dalam platform digital yang dinamis dan interaktif.

Hasil akhirnya adalah Studio Peta Tegalsari, platform Web GIS yang berfungsi sebagai media diseminasi informasi geospasial modern. Seluruh rangkaian, dari akuisisi data primer di lapangan hingga pengembangan aplikasi web, dijelaskan secara komprehensif di sini.

03

Alur Kerja Proyek

Proses pengembangan dibagi menjadi tiga tahapan utama yang saling berkaitan, sesuai metodologi pemetaan partisipatif.

Tahap 1

Pra-Lapangan

1
Persiapan Geodatabase

Membuat struktur geodatabase (.gdb) di ArcGIS Pro untuk menampung data vektor.

2
Deliniasi Awal

Deliniasi bangunan dan penggunaan lahan berdasarkan Orthophoto (foto udara tegak).

3
Formulir Survei Digital

Desain kerangka form survei .xls untuk diunggah ke Ona.io dan digunakan di ODK Collect.

4
Penentuan Sampel

Membuat 50 titik sampel acak (random sampling) untuk uji akurasi penggunaan lahan.

Tahap 2

Lapangan

1
Survei Validasi

Validasi data interpretasi, survei kependudukan, dan pengisian formulir melalui ODK Collect.

2
Pengukuran Batas Presisi

Pengukuran patok dan ICP menggunakan GNSS Geodetik Trimble dan aplikasi Trimble TSM.

3
Dokumentasi Visual

Akuisisi foto udara menggunakan Drone DJI Mavic untuk dokumentasi wilayah.

Tahap 3

Pasca-Lapangan

1
Pengolahan Data SIG

Koreksi, editing, validasi topologi, dan pembuatan layout peta tematik di ArcGIS Pro.

2
Konversi ke Format Web

Ekspor shapefile, lalu konversi menjadi GeoJSON untuk ditampilkan di web.

3
Pengembangan Aplikasi Web

Membangun Landing Page & Studio Peta menggunakan HTML, CSS, JavaScript + MapLibre GL JS.

4
Produk Akhir

Merancang Album Peta digital di Canva dan menyusun Laporan Akhir PKL.

04

Fitur Studio Peta

Aplikasi Studio Peta dilengkapi berbagai fitur untuk eksplorasi data geospasial yang komprehensif dan intuitif.

Manajemen Layer Interaktif

Kontrol penuh untuk menampilkan/menyembunyikan lapisan data: Batas Administrasi, Penggunaan Lahan, Bangunan, Jaringan Jalan, dan Titik Sarana Prasarana.

Kontrol Tampilan Peta

Mengubah basemap (satelit, jalan, gelap, dll.), mengatur pitch untuk efek 3D, dan toggle label peta untuk tampilan lebih bersih.

Legenda Dinamis

Panel legenda yang otomatis menyesuaikan isinya berdasarkan lapisan aktif, termasuk filter sub-kategori dalam sebuah layer.

Antarmuka Multi-Panel

Navigasi tab antara tampilan Peta, Data Tabular, dan Galeri Media dengan tombol unduh yang menyesuaikan konteks panel aktif.

Animasi Pembuka Sinematik

Transisi dari tampilan globe global ke lokasi studi untuk memberikan pengalaman pembuka yang mengesankan dan kontekstual.
