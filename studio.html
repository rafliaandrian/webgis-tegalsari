Tentang Studio Peta Tegalsari

Panduan Teknis, Fitur, dan Alur Kerja Proyek.

Pendahuluan

Studio Peta Tegalsari adalah platform Web GIS interaktif sebagai hasil akhir dari proyek "Akuisisi Data dan Pemetaan Dusun Tegalsari" (PKL 2 · SVIG223439). Mengubah data mentah lapangan menjadi wawasan visual yang dinamis dan mudah diakses.

Alur Kerja Data

1. Akuisisi Lapangan

ODK Collect, GNSS Geodetik Trimble, dan Drone DJI Mavic.

2. Pengolahan SIG

Koreksi, editing, dan validasi topologi di ArcGIS Pro.

3. Konversi Web

Ekspor shapefile menjadi GeoJSON untuk web.

4. Pengembangan Aplikasi

HTML, CSS, JavaScript + MapLibre GL JS.

Panduan Fitur

  • Manajemen Layer: Tampilkan/sembunyikan lapisan data via panel "Atribut Peta".
  • Kontrol Peta: Ganti basemap, atur pitch 3D, dan toggle label peta.
  • Koordinat Live: Koordinat kursor ditampilkan real-time di header atas.
  • Legenda Dinamis: Legenda otomatis menyesuaikan layer aktif.
  • Multi-Panel: Beralih antara Peta, Data, Media, dan Tentang.
